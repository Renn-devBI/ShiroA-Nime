# Ketentuan Penggunaan dan Kebijakan Layanan ShiroA シ

Dokumen ini mengatur hak, kewajiban, dan ketentuan penggunaan aplikasi ShiroA シ serta infrastruktur backend terkait.

---

## 1. Pernyataan Penyangkalan (Disclaimer)

1. Aplikasi ShiroA シ bertindak sebagai pengindeks dan agregator antarmuka pengguna untuk konten media yang tersedia secara publik di internet.
2. ShiroA シ tidak meng-host, mengunggah, atau menyimpan berkas media video, gambar, atau audio berhak cipta pada server aplikasi. Seluruh konten media diperoleh melalui pengurai pihak ketiga dan protokol peer-to-peer (P2P/Torrent).
3. Pengguna bertanggung jawab penuh atas segala aktivitas, kepatuhan hukum hak cipta di wilayah hukum masing-masing, dan materi yang diakses atau diunduh menggunakan aplikasi ini.

---

## 2. Kebijakan Privasi dan Data Pengguna

1. **Otentikasi Akun**: Otentikasi dilakukan menggunakan token API resmi AniList. Aplikasi hanya membaca profil publik (User ID, Nama Pengguna, Avatar) untuk keperluan personalisasi dan sistem komentar internal.
2. **Komentar dan Forum**: Komentar yang dikirimkan oleh pengguna disimpan dalam basis data terenkripsi dan dapat dimoderasi atau dihapus jika melanggar etika komunikasi.
3. **Telemetri dan Laporan Kendala**: Laporan crash yang dikirimkan ke server hanya memuat informasi teknis perangkat (model perangkat, versi Android, log kesalahan sistem) dan tidak mengumpulkan informasi pribadi yang sensitif.

---

## 3. Aturan Komunitas dan Moderasi

1. Dilarang menyebarkan ujaran kebencian, pelecehan, spam, konten ilegal, atau tautan berbahaya pada fitur komentar dan forum.
2. Administrator dan moderator berhak membatasi, menonaktifkan, atau memblokir akses pengguna yang terbukti melanggar ketentuan di atas.

---

## 4. Pembaruan dan Dukungan

Pembaruan aplikasi disediakan secara berkala melalui repositori GitHub resmi ini. Pengguna disarankan untuk selalu memperbarui aplikasi ke versi rilis terbaru demi stabilitas, keamanan, dan keandalan fitur.
